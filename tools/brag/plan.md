# Сценарий видео IMBA TV

## О чём

IMBA TV: экранчик для моноколеса. Подключается к телефону через LoEUC и показывает скорость, ШИМ и заряд колеса, мигает при превышении ШИМ. Прошивка, экраны и заставки настраиваются на сайте, прошивать можно по USB-C или по Bluetooth. Исходники прошивки открыты на github.com/orlovms22/IMBA_TV, инструкции по сборке и авторы проекта в Telegram @IMBA_project.

## Угол

Видео выглядит как руководство по эксплуатации с сайта: бумага, чернила, жёлтая сигнальная краска, подписи «Рис.». Устройство показано в 3D только во вступлении: корпус влетает, включается, камера уходит в экран, и экран становится рисунком на листе. Дальше этот экран живёт на страницах руководства и на сайте. Все картинки экрана сняты с настоящего кода прошивки.

## Визуальная система

- Бумага `#f3f2ed`, чернила `#1d1d1b`, вторичный `#55544e`, линейки `#c8c5b9`, «Внимание» `#f2c230`, OLED `#101010` / `#eef0f2`.
- Sofia Sans Condensed 800 для заголовков, Sofia Sans для текста, моноширинный для адресов.
- Колонтитул как на сайте: «IMBA TV · Руководство», справа раздел и версия, внизу адрес сайта и номер страницы.
- Экран рисуется по точкам с зазором, без свечения. Кадр усредняется по выдержке 1/30 с, поэтому мигание по 50 мс не теряется.
- 3D-корпус по фото: матовый чёрный пластик, сверху мелкая фактура печати, по бокам слои, кнопка спереди почти заподлицо, язычок USB-C слева, на дне велкро, без бликов на экране.

## Звук

Своя дорожка: 125 BPM, ля минор, Am9 · Fmaj9 · Cmaj7 · G6. Такты начинаются со склейки на 2,88 с. Эффекты в той же тональности и том же ревербераторе: свист полёта, стук посадки, щелчок кнопки, звон включения, взрыв, сигналы миганий по пентатонике, щелчки по сайту, штампы этапов прошивки. На выключении экрана плёнка тормозит, затем финальный аккорд. Громкость -14 LUFS.
