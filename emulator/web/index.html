Журнал (Serial, события платы, предупреждения эмулятора)

Телефон с LoEUC подключается, как только плата начинает рекламу, и шлёт пакеты в характеристику. Снятая галочка означает, что поле не передаётся (INT16_MIN).

Сырой пакет

hex, пробелы игнорируются. Формат: 'L' 'E' 01, номер кадра, 2 байта, затем big-endian int16 ×10: скорость, ШИМ, напряжение, заряд, температура, пробег, порог ШИМ.

Что видит прошивка

DnRFНазначениеРежимВыходУровень

Уровень: 1 / 0 / Z (вход без подтяжки или вывод не настроен). Кнопка замыкает D0 на землю. В System OFF выводы сохраняют состояние; пробуждает только вывод в режиме *_SENSE.
