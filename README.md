# Дисплей для отображения телеметрии моноколеса
Дисплей подключается к телефону через программу [LoEUC](https://loeuc.ru/ru/#download) и отображает наиболее важные данные:
* Скорость движения
* ШИМ
* Заряд батареи
* Предупреждения по превышению ШИМ

# Прошивка через браузер
Самый простой способ обновить дисплей — сайт [glazovyuri.github.io/IMBA_TV](https://glazovyuri.github.io/IMBA_TV/):
1. Откройте сайт в Chrome, Edge, Яндекс Браузере или Opera на компьютере (нужна поддержка Web Serial)
2. Выберите версию прошивки или загрузите свой файл (.zip из Arduino IDE, .hex или .uf2)
3. Подключите устройство по USB, нажмите «Прошить» и выберите порт IMBA TV

Плата сама перезагрузится в режим загрузчика. В первый раз браузер попросит выбрать порт загрузчика ещё раз.

Там же можно скачать .uf2: при двойном замыкании RST на GND плата появляется как USB-диск, и файл достаточно скопировать на него.

## Прошивка по Bluetooth
**WIP: на сайте отключена.** С iPhone загрузчик 0.10.0 рвёт связь на первых пакетах данных и остаётся без прошивки, с Mac через CoreBluetooth та же передача проходит. Для отладки её можно включить, открыв сайт с `?ble=1`.

Обновлять дисплей можно и с телефона, без кабеля. Первый раз прошивку с этой функцией нужно залить по USB, дальше:
1. Закройте LoEUC, чтобы он не занял подключение
2. Выключите дисплей и включите его кнопкой, не отпуская её: после логотипа появится полоса, держите, пока она не заполнится (около 4 секунд после того, как загорится экран), — появится экран обновления с QR-кодом сайта. В обычной работе прошить дисплей по Bluetooth нельзя
3. На сайте выберите вкладку «Bluetooth» и нажмите «Прошить по Bluetooth»

Когда сайт подключится, на дисплее появится «Устройство подключено». Дальше прошивку ведёт загрузчик, а он экран не обновляет: картинка замирает до конца прошивки, прогресс показывает сайт. QR-код генерирует `python3 tools/gen_qr.py`, его нужно перезапустить, если поменяется адрес сайта.

Где работает:
* Android и компьютер — Chrome, Edge, Яндекс Браузер
* iPhone — браузер [Bluefy](https://apps.apple.com/app/id1492822055) (Safari и другие браузеры на iPhone не поддерживают Bluetooth)

Режим обновления включается при заряде от 30%: если батарея сядет посреди прошивки, дисплей не включится, пока его не прошить заново. Режим можно запретить в настройках (группа «Обновление по Bluetooth»).

Нужен загрузчик Adafruit 0.10.0 или новее, кроме 0.11.0. В более старых (на платах nice!nano обычно стоит 0.6.0) при сбое записи во флеш загрузчик сам рвёт соединение и перезагружается, а старая прошивка к этому моменту уже стёрта. С iPhone так обрывается почти каждая передача. Поэтому сайт сначала читает версию загрузчика: прошивка сообщает её в Device Information (Software Revision), сам загрузчик — в Firmware Revision. Со старым загрузчиком сайт не прошивает и ничего не стирает, а версию показывает на вкладке «Bluetooth». Такие дисплеи прошивайте по USB.

В 0.11.0 обновление по Bluetooth сломано ([adafruit/Adafruit_nRF52_Bootloader#399](https://github.com/adafruit/Adafruit_nRF52_Bootloader/issues/399)): перед запуском прошивки он запрещает запись в свою область флеша до перезагрузки, а прошивка переходит в загрузчик без перезагрузки. Сайт его тоже не прошивает по Bluetooth; если обновляете загрузчик, ставьте 0.10.0.

## Если прошивка прервалась
Загрузчик Adafruit стирает старую прошивку в начале обновления, поэтому после обрыва (разрядилась батарея, отключился кабель, телефон ушёл далеко) дисплей не включается. Плата при этом не сломана: загрузчик прошивка не затрагивает, недописанную версию он не запустит (проверяет контрольную сумму) и ждёт новую.

Чтобы восстановить, подключите дисплей к компьютеру и прошейте его на сайте по USB-кабелю — в списке устройств загрузчик может называться по названию платы. После обрыва по Bluetooth загрузчик сначала несколько минут ждёт телефон (в это время можно снова прошить по Bluetooth, выбрав AdaDFU) и только потом включает USB: если плата не появилась сразу, подождите до 15 минут. Пока дисплей ждёт прошивку, он не следит за зарядом батареи, так что надолго его в этом состоянии лучше не оставлять.

## Настройки
На сайте можно выбрать экраны, заставку, предупреждение о ШИМ, яркость, батарею колеса и время удержания кнопки. Пересобирать прошивку не нужно: в ней есть блок настроек с описанием формы, сайт записывает в него выбранные значения перед прошивкой. Скачанный с сайта «UF2 с настройками» содержит те же значения. При загрузке из Arduino IDE используются значения по умолчанию.

Как добавить настройку:
1. Описать её в [IMBA_TV/config.json](IMBA_TV/config.json): `key`, тип (`bool`, `u8`, `u16`), `default`, подпись, при необходимости `min`/`max`/`unit`, варианты `options` или условие показа `depends`
2. Запустить `python3 tools/gen_config.py` — он обновит `IMBA_TV/config_gen.h`
3. Использовать значение в коде: `config().key`

Форма на сайте построится сама. CI проверяет, что `config_gen.h` соответствует `config.json`, а собранная прошивка содержит блок настроек со значениями по умолчанию.

У галочек анимаций на сайте есть превью (`"preview"` в config.json): гифки в [web/previews](web/previews/) снимаются с настоящего кода прошивки, собранного на компьютере вместе с GyverOLED. После изменения анимаций или основного экрана пересоберите их: `python3 tools/render_previews.py`.

# Версии и релизы
Прошивку собирает GitHub Actions ([firmware.yml](.github/workflows/firmware.yml)):
* на любой ветке — проверочная сборка, файлы прошивки доступны в артефактах запуска
* на основной ветке — новая версия: тег `vX.Y.Z`, релиз с файлами `.zip`, `.hex` и `.uf2` и обновление сайта

Номер версии увеличивается автоматически (patch). Чтобы поднять minor или major, запустите workflow Firmware вручную (Actions → Firmware → Run workflow) и выберите, какую часть увеличить. Версия прошивки видна по BLE в Device Information Service (Firmware Revision), версия загрузчика — там же в Software Revision.

Сайт лежит в [web/](web/) и публикуется workflow [pages.yml](.github/workflows/pages.yml). Для публикации в настройках репозитория нужно включить GitHub Pages: Settings → Pages → Source: **GitHub Actions**.

# Подготовка среды
## Установка
Для загрузки прошивки потребуется Arduino IDE.

В нее необходимо установить:
* Пакет поддержки плат Adafruit nRF52 [(ссылка)](https://github.com/adafruit/Adafruit_nRF52_Arduino)
* Библиотека для работы с дисплеем GyverOLED [(ссылка)](https://github.com/GyverLibs/GyverOLED)

## Добавление платы
В прдлагаемом пакете нет необходимой нам платы, так что ее необходимо добавить самостоятельно:
1. Ищем путь до данных Arduino IDE
* Windows: %APPDATA%\Local\Arduino15\
* Linux : ~/.arduino15/
* macOS : ~/Library/Arduino15/
2. Переходим в директорию packages/adafruit/hardware/nrf52/1.7.0/
3. Заменяем boards.txt на аналогичный файл, лежащий в директории boards/ проекта
4. копируем imba_pro_micro/ из boards/ в директорию variants/

Если все сделать правильно, то после перезагрузки IDE в списке доступных плат должна появиться "IMBA nRF52840 ProMicro".

# Загрузка
1. Выбираем плату IMBA nRF52840 ProMicro

2. Подключаем устройство к компьютеру по USB и выбираем порт, к которому подвключено устройство

3. Нажимаем кнопку загрузка и ожидаем завершения прошивки
