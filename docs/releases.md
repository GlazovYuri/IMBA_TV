# Версии и релизы
Прошивку собирает GitHub Actions ([firmware.yml](../.github/workflows/firmware.yml)):
* на любой ветке — проверочная сборка, файлы прошивки доступны в артефактах запуска
* на основной ветке — новая версия: тег `vX.Y.Z`, релиз с файлами `.zip`, `.hex` и `.uf2` и обновление сайта
* на ветке `dev` — тестовая версия: тег `vX.Y.Z-dev.N` (X.Y.Z — будущая версия, N растёт с каждой сборкой), pre-release на GitHub и обновление сайта

На сайте тестовые версии подписаны «тестовая». Сами они не выбираются: по умолчанию стоит последняя обычная версия, а в коротком списке над ней видна самая свежая тестовая, если она вышла позже. Остальные тестовые есть в «Все версии». Ссылкой вида `…/IMBA_TV/#v0.5.8-dev.2` можно сразу открыть нужную сборку. Страница сайта всегда публикуется с основной ветки, поэтому правки в `web/` из `dev` попадут на сайт только после слияния.

Номер версии увеличивается автоматически (patch). Чтобы поднять minor или major, запустите workflow Firmware вручную (Actions → Firmware → Run workflow) и выберите, какую часть увеличить. Версия прошивки видна по BLE в Device Information Service (Firmware Revision).

Сайт лежит в [web/](../web/) и публикуется workflow [pages.yml](../.github/workflows/pages.yml). Для публикации в настройках репозитория нужно включить GitHub Pages: Settings → Pages → Source: **GitHub Actions**.
